# 보폭 MCP 성능 개선 학습 문서

이 디렉터리는 일반적인 백엔드 교과서가 아니라 이 저장소에 반영된 보폭 성능 개선 구현을 직접
설명하기 위한 문서다. 운영 수치와 호출 수 요약은 루트의 `PERFORMANCE.md`를 함께 본다.

문서에 언급된 과거 검증용 테스트 파일은 저장소 정책에 따라 현재 버전에는 포함하지 않는다.

## 먼저 이것부터 읽기

처음부터 모든 상세 문서를 읽지 않아도 된다. 먼저
[가장 쉬운 시작](./00-easy-start.md)만 읽으면 전체 흐름과 핵심 개념을 한 번에 볼 수 있다.

```text
처음 공부할 때
00 가장 쉬운 시작
↓
실제 코드 5개 따라가기
↓
궁금한 주제만 상세 문서에서 찾아보기
↓
마지막에 체크리스트 풀기
```

## 코드와 문서를 함께 읽는 방법

`00-easy-start.md`에서 큰 그림을 잡은 뒤, 표시된 핵심 함수만 IDE에서 따라간다. 이해가 안 되는
개념이 나올 때만 해당 상세 문서를 열고, 마지막에 테스트와 체크리스트로 확인하는 방식이 가장
편하다.

## 구현 여부 범례

- **구현**: 현재 저장소 버전에 코드가 반영돼 있다.
- **기존 유지/점검**: 새 구현은 아니지만 이번 작업에서 동작을 확인했다.
- **검토 후 미적용**: 설계상 고려했으나 현재 저장소 버전에는 반영하지 않았다.
