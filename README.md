# Barrier Free Trip

Accessible travel MCP server project.

## Stack

- Node.js 24 LTS
- TypeScript
- ESM
- npm
- `@modelcontextprotocol/sdk@1.29.0`
- Zod 4
- Node built-in `fetch`
- Vitest
- ESLint + typescript-eslint
- Prettier
- Local MCP transport: stdio
- Future cloud transport: Streamable HTTP

## Scripts

- `npm run build`
- `npm run typecheck`
- `npm run lint`
- `npm run format:check`
- `npm test`
